## 二、「工作」键（`control_work` = `Action` = 101）能操作的动作

这是直接回答你问题的部分——绑定在「工作」键上的全部交互：

| 游戏内显示名 | 本地化键 | 说明 |
|---|---|---|
| **工作** | `hint_work` | ★ 砍树、挖矿、挖黏土/沙、耕地、收割——**所有持续劳动** |
| **打水** | `hint_draw_water` | 从水井打水 |
| 拿取 | `hint_take` | 拾取掉落物 |
| 全部拿取 | `hint_take_all` | 一次收取范围内全部掉落物 |
| 放置 | `hint_put` | 放下手持物品 |
| 打开 | `hint_open` | 打开容器/门 |
| 检查 | `action_inspect` | 检视物件信息 |

其中 **只有「工作」和「打水」是「工作」键独有**的；后 5 个同时也绑在「交互」键上（两个键都能用）。

## 四、为什么不同目标的触发键不一样

游戏允许**每个物件单独配置交互键**，反编译里能看到：

```csharp
LocalizeHintWithActionIcon(hint, assignedWgo.Data.Definition.customInteraction.gameKey);
LocalizeHintWithActionIcon(hint, assignedWgo.Data.Definition.customInteraction2.gameKey);
```

实测差异：

| 目标 | 触发的键 | 数值 |
|---|---|---|
| 树木 / 矿石 / 黏土坑 / 农田 | 「工作」`Action` | 101 |
| 纺车 / 制作台界面 | `StartCraft` | 201 |
| 开门 / 开箱 | 「交互」`Interaction` | 100 |

这就是 mod 里**不能用"工作键白名单"**的原因——黏土坑"有时能持续有时不能"就是它没落在白名单里。

> **注意（2026-09-27 更新）**：早期版本用过 `ExcludedKeys = 100,144` 这类排除法配置，
> **现在已不存在**。当前判据是「该动作有没有进度条」（见 `README.md`），
> 既不维护工作键白名单，也不维护排除名单。
>
> 另外，插件里用到的「键位 → GameKey」**完全来自游戏自己的绑定表**
> （`LazyInput.GameBindings.keyBindings` / `gamepadBindings`），
> 所以下面这些数值只用于理解游戏机制，不需要在插件里维护。
>
> Superseded: `ExcludedKeys` no longer exists. The plugin now uses the progress-bar
> rule, and all key mapping is read from the game's own bindings.
